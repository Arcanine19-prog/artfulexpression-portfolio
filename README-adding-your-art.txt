Swapping in a different piece
-------------------------------
Replace the image file at the path above (keep the same filename) and
it updates automatically - no code changes needed. To change the title
or description under a piece, edit the matching <article class="feature
reveal"> block in index.html.

Adding a 6th (or more) piece
-------------------------------
Copy one whole <article class="feature reveal">...</article> block in
the Gallery section of index.html, point feature-img at a new image
path, and update the medium tag, title, description and mailto subject.
